# LU Decomposition 

## AIM:
To write a program to find the LU Decomposition of a matrix.

## Equipments Required:
1. Hardware – PCs
2. Anaconda – Python 3.7 Installation / Moodle-Code Runner

## Algorithm
1. Import the required libraries numpy and scipy.linalg.
2. Read the co-efficient matrix and constant matrix from the user.
3. Use lu_factor() to factorise the co-efficient matrix into LU form.
4. Use lu_solve() with the LU factorization and constant matrix to find the solution.
5. Display the solution matrix(x).
